
### ✨ Особенности

* 🖥️ **macOS Window Interface** — стилизация под окно терминала macOS с кастомными кнопками управления.
* 🎨 **Темы оформления** — динамическое переключение цветовых схем (Dark, Red, Green, Purple, Blue) с интерактивным эффектом Matrix / Particles на Canvas.
* 🌐 **Мультиязычность (i18n)** — мгновенная смена языка (RU / EN) без перезагрузки страницы.
* 💻 **Встроенный CLI-терминал** — интерактивная консоль с поддержкой команд (`help`, `neofetch`, `theme`, `ping`, `sudo` и др.).
* ⌨️ **Пасхалки** — открытие консоли при наборе определённых ключевых слов на клавиатуре или по кликам на аватар.
* 🕒 **Динамический статус** — автоматическое отслеживание часового пояса (Киров, UTC+3) и отображение статуса *в сети / сплю*.
* 🔊 **Sound Effects** — процедурная генерация звуковых эффектов через Web Audio API (без внешних аудиофайлов).
* 📱 **Адаптивность** — полная поддержка мобильных устройств и кастомный курсор для десктопов.

---

### 🛠 Технологии

* **Frontend:** HTML5, CSS3 (Custom Variables, Flexbox, Grid)
* **Scripting:** Pure JavaScript (ES6+)
* **Graphics:** HTML5 Canvas API
* **Audio:** Web Audio API
* **Icons & Fonts:** Material Symbols, FontAwesome, Google Fonts (Roboto, JetBrains Mono)
